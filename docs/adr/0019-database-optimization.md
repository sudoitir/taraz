# 0019. انضباط بهینه‌سازی PostgreSQL

**وضعیت:** پذیرفته‌شده
**تاریخ:** ۲۰۲۶-۰۸-۱۸

## زمینه

عملکرد دیتابیس از روز اول یک تصمیم طراحی است، نه بهینه‌سازی بعد از بحران.

## تصمیم

انضباط‌های Postgres: نوع و اندازه‌ی درست ستون‌ها، **مرتب‌سازی ستون‌ها** (fixed-width اول) برای alignment، تنظیم **autovacuum**، و index آگاهانه.

## پیامدها

- هر migration (ADR-0014) باید به این انضباط‌ها پایبند باشد و در review بررسی شود.
