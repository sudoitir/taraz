# 0017. قفل خوش‌بینانه با `@Version`

**وضعیت:** پذیرفته‌شده
**تاریخ:** ۲۰۲۶-۰۸-۱۸

## زمینه

به‌روزرسانی هم‌زمان‌ی یک حساب باید بدون lost update و بدون قفل‌گذاری سنگین دیتابیس کنترل شود.

## تصمیم

**Optimistic locking** با فیلد **`@Version`** در JPA روی Entity حساب.

## پیامدها

- تداخل هم‌زمانی با خطای version مشخص و retry در لایه‌ی بالاتر مدیریت می‌شود؛ رفتار retry باید مستند شود.
