# 0023. تست قوانین معماری با ArchUnit

**وضعیت:** پذیرفته‌شده
**تاریخ:** ۲۰۲۶-۰۸-۱۸

## زمینه

مرزهای معماری صریح (ADR-0006) بدون enforce خودکار در review فرسوده می‌شوند.

## تصمیم

قوانین معماری (جهت وابستگی لایه‌ها، ممنوعیت دسترسی دامنه به framework، قراردادهای نام‌گذاری) با **ArchUnit** به‌صورت تست enforce می‌شوند.

## پیامدها

- شکستن مرز لایه‌ها = قرمزشدن build؛ قوانین در `src/test` زندگی می‌کنند و با هرم تست اجرا می‌شوند.
