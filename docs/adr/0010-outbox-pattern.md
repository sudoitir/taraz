# 0010. الگوی Outbox برای انتشار رویداد

**وضعیت:** پذیرفته‌شده
**تاریخ:** ۲۰۲۶-۰۸-۱۸

## زمینه

ثبت تغییر موجودی و انتشار رویداد باید اتمیک باشد؛ بدون dual-write ناقص.

## تصمیم

**الگوی Outbox**: Integration Event در همان تراکنش دیتابیسِ تغییر حالت در جدول outbox ثبت و سپس async منتشر می‌شود.

## پیامدها

- حداقل یک‌بار تحویل (at-least-once) — مصرف‌کننده باید idempotent باشد.
