# 0004. justfile به‌عنوان نقطه‌ی ورود یکتا برای Taskها

**وضعیت:** پذیرفته‌شده
**تاریخ:** ۲۰۲۶-۰۸-۱۸

## زمینه

دستورهای روزمره (build، test، run، بالاآوردن infra با docker-compose، اجرای k6) اگر در README و حافظه‌ی توسعه‌دهنده پراکنده باشند، drift می‌گیرند. چالش یک دستور استاندارد (`./mvnw test`) می‌خواهد؛ justfile باید همان را کپسوله کند، نه جایگزین.

## تصمیم

همه‌ی Taskهای روزمره از طریق **justfile** اجرا می‌شوند؛ `just test` در پس‌زمینه همان `./mvnw test` است.

## گزینه‌های بررسی‌شده

- **Makefile** — رد شد: سینتکس tab-محور و semantic قدیمی‌اش برای task-runner بودن طراحی نشده؛ just برای همین کار ساخته شده.
- **فقط `./mvnw` و دستورهای مستقیم** — رد شد: دستورهای compose و k6 پراکنده می‌مانند و نقطه‌ی ورود یکتا از بین می‌رود.

## پیامدها

### مثبت

- README فقط به دستورهای `just` ارجاع می‌دهد؛ `./mvnw test` همچنان استاندارد بیلد و دروازه‌ی CI باقی می‌ماند.

### منفی / بدهی فنی

- یک ابزار اضافه برای نصب (`just`)؛ برای داور، `./mvnw test` مستقل از آن کار می‌کند.
