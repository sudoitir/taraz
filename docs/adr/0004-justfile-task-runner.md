# 0004. justfile به‌عنوان نقطه‌ی ورود یکتا برای Taskها

**وضعیت:** پذیرفته‌شده
**تاریخ:** ۲۰۲۶-۰۸-۱۸

## زمینه

دستورهای build/test/run باید یک جا و یک‌شکل در دسترس باشند.

## تصمیم

همه‌ی Taskهای روزمره (build، test، run، k6، …) از طریق **justfile** اجرا می‌شوند.

## پیامدها

- README فقط به دستورهای `just` ارجاع می‌دهد؛ `./mvnw test` همچنان استاندارد بیلد باقی می‌ماند.
