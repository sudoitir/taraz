# 0008. رهنمودهای REST API بر مبنای Zalando

**وضعیت:** پذیرفته‌شده
**تاریخ:** ۲۰۲۶-۰۸-۱۸

## زمینه

اگر REST API ارائه شود (در چالش اختیاری است)، باید از یک rulebook استاندارد پیروی کند.

## تصمیم

پیروی از **Zalando RESTful API Guidelines**؛ فرمان‌های موفق با **`201 Created`** و هدر **`Location`** پاسخ می‌دهند؛ هدرهای استاندارد رعایت می‌شوند.

- مرجع: http://opensource.zalando.com/restful-api-guidelines/

## پیامدها

- قرارداد API قابل‌پیش‌بینی و مستند است؛ داوری API ساده می‌شود.
