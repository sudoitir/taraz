# 0016. کلید اصلی UUID v7 با B-tree index

**وضعیت:** پذیرفته‌شده
**تاریخ:** ۲۰۲۶-۰۸-۱۸

## زمینه

کلیدهای تصادفی (UUID v4) الگوی درج B-tree را خراب می‌کنند؛ sequence هم تولید distributed را سخت می‌کند.

## تصمیم

کلید اصلی همه‌ی جدول‌ها **UUID v7** (مرتب‌شونده بر اساس زمان) با **B-tree index** است.

## پیامدها

- درج‌ها به انتهای index می‌روند (page locality بهتر)؛ تولید ID سمت اپلیکیشن و بدون round-trip.
