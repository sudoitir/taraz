# 0001. اسکفولد پروژه با JHipster

**وضعیت:** پذیرفته‌شده
**تاریخ:** ۲۰۲۶-۰۸-۱۸

## زمینه

برای شروع سریع پروژه با ساختار استاندارد Spring Boot به یک مولد پروژه نیاز داریم.

## تصمیم

اسکفولد اولیه‌ی پروژه با **JHipster** انجام می‌شود.

## پیامدها

- سازگاری نسخه‌ی تولیدشده با **Spring Boot 4.1.0** باید هنگام اسکفولد بررسی و در صورت عقب‌بودن ژنراتور، ارتقا داده شود.
- خروجی ژنراتور باید با معماری صریح (ADR-0006) تطبیق داده شود؛ هر آنچه اضافه است حذف می‌شود.
