# 0018. مرز تراکنش در جای درست

**وضعیت:** پذیرفته‌شده
**تاریخ:** ۲۰۲۶-۰۸-۱۸

## زمینه

بازکردن تراکنش «به‌عادت» در application service مرز اتمیسیته واقعی (مانند transfer دوحسابه یا outbox) را مخفی می‌کند.

## تصمیم

تراکنش دقیقاً در همان مرزی باز می‌شود که اتمیسیته در آن تعریف شده (command handler / واحد اتمیک واقعی) — نه صرفاً به‌صورت پیش‌فرض در لایه‌ی application service.

## پیامدها

- مرز هر تراکنش باید در کد صریح و در review قابل‌اشاره باشد؛ transaction طولانی روی چند فرمان ممنوع.
